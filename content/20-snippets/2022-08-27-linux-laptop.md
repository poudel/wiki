I switched to a Mac for personal and work computing a while ago. But I
still wanted a linux machine to play with. So I bought a refurbished
Thinkpad T470 to use as a "lab" machine. The thing that struck me
immediately was how snappy this machine is. And how fast magit on it
is compared to my macOS machines.

By now I've installed arch for probably a dozen times. But this is the
first time I decided to use archinstaller, and I really enjoyed the
experience. I'm using KDE plasma, nothing too fancy but I would like
to try a tiling window manager to see if it's something that I'd
enjoy.
